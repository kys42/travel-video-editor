01

에이전트에게 맡길 수 있는 일

자연어로 요청하면 계약에 정의된 도구 조합으로 처리합니다.

각 예시는 Edit Desk 입력창으로 바로 전달됩니다. 자동 실행하지 않으므로 내용을 확인하고 전송할 수 있습니다.

02

요청이 편집 revision이 되기까지

전체 영상을 모델이 순차 시청하지 않는 토큰 절약형 경로입니다.

검색 결과는 먼저 에이전트만 읽고, 사용자에게 유효한 후보만 카드로 표시합니다.

01 · CONTEXT

작업공간 맥락 확인

현재 영상, 포커스 장면과 여러 영상에 걸쳐 명시적으로 선택한 장면 요약을 도구 호출 없이 읽습니다.

02 · SEARCH

요약 인덱스 검색

선택 범위 밖의 소재가 필요할 때만 설명, 행동, 대화와 특이 포인트를 검색합니다.

03 · EVIDENCE

후보만 상세 확인

모호한 후보에 한해 세부 행동, 원문 발화와 프레임 참조를 읽습니다.

04 · PLAN

편집 구성 제안

사용할 장면, 순서, 예상 길이, 주요 대사와 선택 이유를 설명하고 의견을 묻습니다.

05 · REVISE

확인 후 revision 생성

사용자가 동의하거나 수정한 계획을 원본 타임코드 기반 작업으로 검증해 저장합니다.

06 · REVIEW

Edit Desk로 검토

장면 카드, 변경 요약과 소스 모니터 액션을 같은 SSE 스트림으로 보냅니다.

03

05

권한과 안전 경계

모델의 판단과 실제 편집 권한은 서버의 Tool Gateway에서 분리됩니다.

Codex는 도구 호출을 제안합니다. 입력 검증, 리비전 충돌 검사와 실제 저장은 서버가 담당합니다.

READ · NO APPROVAL

읽을 수 있음

  • 영상별 요약과 촬영 순서
  • 검토된 장면·행동·대화
  • 특이 포인트와 프레임 참조
  • 현재 및 과거 편집 revision
WRITE · DRAFT ONLY

변경할 수 있음

  • 새 러프컷 초안 만들기
  • 컷 추가·trim·이동·제거
  • 편집 제목과 목표 길이
  • 항상 새 revision으로 저장
UI · REVERSIBLE

화면에서 할 수 있음

  • 장면 상세 위치로 이동
  • 소스 모니터 구간 재생
  • Monitor/AI 탭 전환
  • 장면·편집 참조 카드 표시
BLOCKED · OUT OF SCOPE

할 수 없음

  • 4K 원본 삭제·이동·덮어쓰기
  • 임의 셸·파일시스템 실행
  • 확인되지 않은 장면 추측
  • 무승인 최종 렌더·업로드
06

응답과 화면 제어 프로토콜

텍스트, 카드와 화면 액션은 같은 cancelable SSE 스트림으로 전달됩니다.

브라우저는 서버가 보낸 임의 코드를 실행하지 않고 닫힌 타입의 의미 기반 액션만 처리합니다.

status

검색·조회·revision 적용 진행 상태

card

장면 후보와 편집 결과 참조 카드

action

재생·포커스·인스펙터 전환

text

에이전트의 설명과 결과 요약

suggestions

현재 결과에 맞는 후속 요청

done

세션·활성 edit와 정상 종료

error

코드·재시도 가능 여부가 있는 실패

모든 에이전트 동작의 단일 기준은 editor-agent-contract/v1입니다. 컨텍스트 resolver, 에이전트 프롬프트, Tool Gateway, 이 가이드와 테스트가 같은 계약을 소비합니다.
