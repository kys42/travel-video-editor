# 파일럿 실행 계획

## 목적

10일치 전체 영상을 처리하기 전에 하루치 또는 30~60분 분량으로 다음 사항을 검증합니다.

- 실제 카메라 코덱을 안정적으로 읽을 수 있는지
- 프록시의 화질·크기·생성 속도가 적절한지
- 한국어 및 여행지 언어의 STT 품질이 충분한지
- 음성이 없는 액션캠 장면을 대표 프레임으로 잘 찾을 수 있는지
- 자동 추천 클립이 사람이 고른 장면과 어느 정도 일치하는지
- 러프컷을 FFmpeg와 OTIO로 재현할 수 있는지

## 시작 전 필요한 정보

- [ ] 카메라 제조사와 모델
- [ ] 원본 폴더의 절대 경로
- [ ] 원본 폴더를 읽기 전용으로 사용할 수 있는지
- [ ] 파일럿 대상 날짜 또는 폴더
- [ ] 작업 미디어 저장 경로
- [ ] 클라우드 API 사용 허용 여부
- [ ] 주요 언어와 동행 인원
- [ ] 우선 출력 프로필
- [ ] 선호 NLE 또는 NLE 없음

## 파일럿 범위

기본안:

- 원본 영상 30~60분
- 서로 다른 조건 포함: 낮, 밤, 실내, 야외, 대화, 무음 풍경, 빠른 움직임
- 원본은 읽기 전용
- 파생 자료는 별도 파일럿 디렉터리에 저장
- 자동 삭제 없음
- 클라우드 업로드는 별도 승인 전까지 없음

## 단계별 작업

### 단계 A: 읽기 전용 감사

- 파일 개수와 총 용량 계산
- 총 재생 시간 계산
- 코덱, 해상도, FPS, 회전, 오디오 확인
- 촬영 시각의 정확성과 타임존 확인
- 연속 촬영 세그먼트와 중복 파일 확인
- GPS/자이로 메타데이터 유무 확인

산출물:

- `inventory-report.md`
- `assets.csv`
- `assets.jsonl`

### 단계 B: 파생 자료 샘플

- 720p 프록시 생성
- STT용 음성 추출
- 5~15초 간격 프레임과 장면 대표 프레임 생성
- 연락판 생성

산출물:

- 프록시 샘플
- 음성 샘플
- 프레임 디렉터리
- `contact-sheet.html`

### 단계 C: 전사와 분석

- 로컬 STT
- 타임스탬프 품질 확인
- 장면 설명과 OCR
- 흐림·노출·흔들림·음량 지표
- 검색 태그 생성

산출물:

- `transcript.json`
- `transcript.srt`
- `scenes.jsonl`
- `quality.jsonl`

### 단계 D: 편집 후보

같은 파일럿 자료에서 세 가지 편집안을 만듭니다.

1. 60~90초 하이라이트
2. 5~8분 개인 여행기
3. 5~8분 YouTube형 구성안

산출물:

- `selects.csv`
- `edit-plan-personal.json`
- `edit-plan-youtube.json`
- 리뷰용 MP4
- OTIO 또는 FCPXML

### 단계 E: 평가와 확장 결정

- 좋은 장면 누락률
- 불필요한 장면 포함률
- STT 고유명사 오류
- 타임코드 오차
- 프록시 시간과 저장 용량
- 자동 컷의 시청 가능성
- 10일치 전체 처리 예상 시간과 용량

## 합격 기준

- 모든 선택 클립이 원본 경로와 타임코드로 재현됨
- 원본 파일의 크기·수정 시각·내용이 변하지 않음
- 프록시에서 편집 판단에 필요한 화질이 유지됨
- 대화 구간의 대부분을 검색할 수 있음
- 음성이 없는 주요 장면도 연락판이나 검색에서 찾을 수 있음
- 리뷰 미리보기와 OTIO/FCPXML의 컷 순서가 일치함
- 사용자가 전체 처리 전에 출력 스타일을 조정할 수 있음

## 예상 위험과 대응

| 위험 | 대응 |
|---|---|
| 내부 저장 공간 부족 | 프록시와 프레임을 외장 SSD에 저장하고 예상 크기부터 계산 |
| 촬영 시각 오류 | 파일 시각, MP4 메타데이터, GPS 시각을 비교 |
| 액션캠 원테이크에서 장면 탐지 실패 | 고정 주기 샘플링과 움직임·음성 이벤트 병행 |
| STT가 바람 소리와 고유명사에 약함 | VAD, 언어 힌트, 장소명 사전, 선택적 클라우드 재전사 |
| 자동 편집이 과감하게 원본을 제외 | 제외 대신 점수와 사유를 기록하고 사람이 최종 승인 |
| MCP가 원치 않는 쓰기 작업 수행 | 복제 프로젝트, 허용 경로, 도구별 승인 게이트 사용 |
| 타인 얼굴·사적 대화 노출 | 공개용 프로필에 별도 개인정보 검토 단계 적용 |

## 전체 10일치로 확장할 조건

- 파일럿 설정과 스키마가 확정됨
- 필요한 작업 공간이 계산됨
- 카메라별 예외가 문서화됨
- 자동 추천 결과를 사용자가 승인함
- 재시작 가능한 체크포인트와 처리 로그가 있음
- 실패 파일만 다시 처리할 수 있음
