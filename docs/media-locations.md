# 소스 미디어와 작업 미디어 위치

이 문서는 현재 Mac에서 Travel Video Editor가 사용하는 미디어 루트와 각 저장소의 역할을 기록합니다. 대용량 영상은 Git 저장소 밖에 두며, 코드와 작은 구조화 데이터만 저장소에서 관리합니다.

## 현재 위치

| 역할 | 볼륨 | 경로 | 취급 |
|---|---|---|---|
| 4K 원본 및 카메라 원본 | `T7` | `/Volumes/T7/시애틀알래스카` | 읽기 전용·영구 보존 |
| 1080p 작업 프록시 | `ExternalSSD` | `/Volumes/ExternalSSD/travel-video-editor/proxies/1080p-h264` | 분석·검토용, 재생성 가능한 캐시 |
| 코드와 작은 분석 산출물 | 프로젝트 저장소 | `/Users/kys/projects/travel-video-editor` | Git 추적 또는 `work/` 로컬 산출물 |

macOS에서 한글 볼륨 경로는 디스크에 분해형 Unicode로 저장될 수 있습니다. 화면과 문서에서는 위처럼 읽기 쉬운 이름을 사용하되, 자동화에서는 셸로 실제 경로를 확인하거나 기존 manifest의 `source_root` 값을 사용합니다.

## 4K 원본

원본 루트는 다음 여섯 폴더를 포함합니다.

| 상대 폴더 | 현재 영상 후보 수 |
|---|---:|
| `0826` | 51 |
| `0827` | 55 |
| `0828` | 27 |
| `0829` | 26 |
| `cam` | 198 |
| `cam2-0825` | 43 |
| 합계 | 400 |

2026-09-02 기준 현재 소스 루트의 영상 후보는 약 370.64 GiB입니다. 이전에 `0829`에 겹쳐 있던 복사본은 사용자가 소스 루트 밖으로 옮겼으며, 현재 수치는 이동 후 기준입니다.

`cam/DJI_20260824031646_0005_D.MP4`는 1,241바이트짜리 재생 불가 stub입니다. 삭제하지 않고 `invalid_or_stub`로 기록하며 배치 처리에서는 건너뜁니다.

원본 운영 규칙은 다음과 같습니다.

- 파이프라인은 T7 원본을 읽기만 하며 이름 변경, 덮어쓰기, 이동과 삭제를 하지 않습니다.
- 모든 장면·대화·편집 결정은 `source relative path + source_in + source_out`으로 원본까지 역추적합니다.
- 최종 편집과 렌더는 프록시가 아니라 이 원본에 같은 타임코드를 적용합니다.
- 원본 루트가 마운트되지 않았을 때는 경로를 추측하거나 다른 파일로 자동 대체하지 않습니다.

## 1080p 작업 프록시

현재 프록시는 원본의 상대 폴더 구조와 파일명을 유지해 `ExternalSSD`에 생성합니다. 예를 들면 다음과 같습니다.

```text
원본:   /Volumes/T7/시애틀알래스카/0826/DJI_20260827054939_0001_D.MP4
프록시: /Volumes/ExternalSSD/travel-video-editor/proxies/1080p-h264/0826/DJI_20260827054939_0001_D.mp4
```

현재 프로필은 최대 1920×1080, H.264 VideoToolbox, 기본 6 Mbps, 45fps 이상 8 Mbps, 원본 FPS 유지, AAC 오디오 스트림 복사입니다. 프록시는 원본과 같은 시작점과 재생 길이를 유지하도록 생성 후 검증합니다.

배치 상태와 파일별 이력은 프록시 루트에 별도로 보존합니다.

- `proxy-summary.json`: 현재 진행률, 설정, 실패 수와 압축률
- `proxy-manifest.jsonl`: 시작·완료·재사용·실패 이력과 원본/프록시 probe
- `logs/`: 파일별 FFmpeg 로그

프록시는 분석, 웹 타임라인 재생, 장면 확인과 러프컷 판단에 사용합니다. 삭제 후 같은 설정으로 재생성할 수 있지만 manifest와 원본 타임코드 기반 편집 데이터는 장기 보존합니다.

## 경로 계약

애플리케이션에서 경로를 하드코딩하기보다 다음 두 루트를 실행 설정으로 주입합니다.

```text
SOURCE_MEDIA_ROOT=/Volumes/T7/시애틀알래스카
WORKING_MEDIA_ROOT=/Volumes/ExternalSSD/travel-video-editor
```

`asset_id`는 볼륨명이 아니라 원본 상대 경로와 콘텐츠 지문을 기준으로 안정화합니다. 따라서 볼륨이 나중에 교체되거나 마운트 이름이 바뀌어도 루트만 다시 지정하면 기존 분석과 편집 결정을 연결할 수 있어야 합니다.
