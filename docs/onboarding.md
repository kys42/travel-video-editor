# 처음 사용하기: 설치 점검부터 원하는 영상까지

스킬은 설치 순간에 프로그램을 자동 실행하지 않습니다. Claude Code나 Codex에서 처음 호출하면 필요한 준비를 점검하고 작업 목적을 묻도록 구성되어 있습니다. 다시 시작할 때는 저장된 설정을 읽고 달라진 내용만 확인합니다.

> 처음 사용하는 환경이야. travel-video-pipeline 스킬로 준비 상태를 점검하고,
> 필요한 설치를 도와준 다음, 영상 소스와 원하는 작업을 같이 정해줘.

## 처음에 진행하는 순서

| 단계 | AI가 확인하거나 묻는 것 | 남는 결과 |
|---|---|---|
| 1. 작업 선택 | 장면·대사 웹만 / 추출부터 하이라이트까지 / 기존 자료로 편집 | 처리 범위 |
| 2. 환경 점검 | OS, Python, FFmpeg, 프로젝트 환경, 필요한 음성 모델 | 준비 상태와 필요한 설치 목록 |
| 3. 설치 안내 | 선택한 작업에 필요한 것만 설치하고 실제 준비 여부 재확인 | 실행 가능한 환경 |
| 4. 소스 확인 | 영상·기존 라이브러리 위치, 날짜 범위, 파일 수·용량, 작업 저장소 | 입력과 출력 위치 |
| 5. 편집 방향 | 만들 영상의 목적·내용·길이·화면·대사·자막·음악·제외 조건 | 편집 brief |
| 6. 실행 | 추출·웹 생성, 필요하면 후보 선정과 미리보기·최종 렌더 | 요청한 결과물 |

이미 알려준 경로와 조건은 다시 묻지 않습니다. 처음에는 파일 목록과 용량만 가볍게 확인하며, 점검 요청만으로 모델을 다운로드하거나 전체 영상을 분석하지 않습니다. 설치까지 요청했다면 필요한 설치를 진행하고 재확인합니다.

## 어떤 준비가 필요한가요?

**이미 분석된 라이브러리로 편집한다면** FFmpeg·ffprobe, Python/Pillow, 영상 경로와 출력 공간을 점검합니다. Apple 음성 모델을 새로 설치할 필요가 없습니다.

**새 영상에서 대사를 추출한다면** 사용할 언어와 음성 처리 방식을 정합니다. Apple Speech 경로는 macOS 26 이상과 호환 기기·Swift 환경이 필요하며, MLX는 별도 환경과 모델을 사용합니다. 지원하지 않는 환경에서는 기존 대사를 가져오거나 사용자가 선택한 시각 정보 추출 범위로 진행합니다. 음성 준비가 안 됐다고 해당 영상을 “대사 없음”으로 처리하지 않습니다.

**Apple 음성 모델**은 빌드 성공만으로 준비됐다고 판단하지 않습니다. 실제 선택한 언어의 전사 모듈과 음성 Detector 자산을 점검합니다.

```bash
# 프로젝트 루트에서 실행
swift build --package-path apple-speech -c release
apple-speech/.build/release/apple-speech capabilities

# 상태 조회: 다운로드·영상 처리 없음
apple-speech/.build/release/apple-speech assets --locale ko-KR
apple-speech/.build/release/apple-speech assets --locale en-US

# 설치가 필요하고 설치하기로 한 경우
apple-speech/.build/release/apple-speech assets --locale ko-KR --install
apple-speech/.build/release/apple-speech assets --locale en-US --install
```

`status_after`가 `installed`여야 준비 완료입니다. 새 `assets` 명령이 없는 구버전 worker는 소스를 업데이트하고 다시 빌드합니다. 상세 내용은 [Apple Speech worker](../apple-speech/README.md)에 있습니다.

## 영상 제작을 선택하면 이런 대화를 합니다

한 번에 긴 설문을 던지지 않고 필요한 내용을 두세 가지씩 확인합니다.

> **AI:** 장면·대사를 정리한 웹까지만 만들까요, 하이라이트 영상까지 만들까요?
>
> **사용자:** 영상까지. 가족에게 보여줄 여행 기록이야.
>
> **AI:** 풍경·음식·대화 중 무엇을 중심으로 남기고 싶으세요? 원하는 길이와 가로·세로 화면도 알려주세요.
>
> **사용자:** 풍경과 음식 중심으로 3분, 가로 화면. 현장 대사는 살리고 싶어.
>
> **AI:** 그 방향으로 구성하겠습니다. 자막이나 음악을 넣을지, 제외할 얼굴·장면·개인적인 대화가 있는지도 확인할게요.

장면 추출만 선택하면 영상 길이·배경음악·화면 비율을 묻지 않습니다. 구체적인 편집안으로 바로 렌더를 요청한 경우도 같은 설문을 처음부터 반복하지 않습니다.

## 설정은 다음 작업에도 이어집니다

선택한 소스와 목적, 언어, 영상 옵션은 로컬 `work/onboarding/profile.json`에 저장합니다. 추출이 끝나고 `video-editor`로 넘어갈 때도 같은 brief를 전달하므로 다시 설명할 필요가 없습니다. 새 컴퓨터나 연결이 바뀐 저장소에서는 필요한 환경만 재점검합니다.

이 파일에는 실제 개인 경로와 제외 조건이 담길 수 있어 Git에 올리지 않습니다. “공개용 영상”이라는 목적은 파일 업로드나 저장소 공개 전환에 대한 승인이 아닙니다. 공개가 필요하면 이미지, 대사, 경로, 메타데이터와 Git 이력을 별도로 확인합니다.

## 스킬 설치와 호출

저장소의 두 스킬 폴더에는 `SKILL.md`, 참고 문서와 실행 스크립트가 함께 들어 있습니다. 사용하는 에이전트의 스킬 설치 기능으로 폴더 전체를 설치하거나, 이 저장소를 연 상태에서 해당 `SKILL.md`를 읽도록 요청하세요. 설치본을 업데이트할 때도 새 `references/onboarding.md`를 함께 전달해야 합니다.

- [travel-video-pipeline](../skills/travel-video-pipeline/SKILL.md): 환경·소스·처리 범위를 확인하고 추출부터 시작합니다.
- [video-editor](../skills/video-editor/SKILL.md): 기존 후보·편집안을 받아 필요한 렌더 환경과 영상 방향을 확인합니다.

이 프로젝트의 실행 코드가 없는 독립 스킬 설치만으로 모든 분석 명령이 준비되는 것은 아닙니다. 처음 사용할 때 저장소와 런타임도 찾아 연결하도록 안내합니다.
