# 편집용 추출 근거 v1 소규모 실험

2026-09-07. 실행·계약 연결을 확인한 파일럿이며, 사건/인물 인식 정확도 또는 좋은 클립 선정의 벤치마크는 아니다.

## 실제 프록시와 모델 리뷰

기존 분석이 있는 58.058초 영상 한 편(야외 푸드코트/화로 좌석)을 사용했다. 기존 raw Apple STT·시각 프레임·거친 그룹·경계/시각 순간을 재사용했다. 이전 LLM 리뷰/확정 자막은 새 리뷰 입력으로 제공하지 않았다.

| 단계 | 확인 결과 |
|---|---|
| Apple Vision | 약 3fps, 시각 175샘플·OCR 59샘플 |
| 양성 검출 | 얼굴 76건·사람 279건. 같은 사람이 반복 검출되므로 고유 인원수가 아님 |
| Vision 시간 | 최초 정상 실행 2.681초, 빈 결과 방어 포함 최종 바이너리 2.303초 |
| LLM | 완전한 그룹 2개(0–35초, 35–58.058초), 그룹별 리뷰와 validator 수정 |
| 대화 | 발화 9개·자막 9개 보존 |
| 후보 | 8개, 그중 구조화 후보 5개·추가 검토 3개 |
| 인물 | 비트별 익명 인물 기록 8개. 고유 인원수가 아니며 신원/화자 연결 미확인 |
| 얼굴 정책 | 8개 모두 unknown. 얼굴 제외 자동 승인 없음 |
| 연결 | packet → 그룹 review → shard merge → 전체 timeline merge → candidate export 통과 |

LLM이 처음 신원 불확실성을 이유로 화면 인물 기록까지 비워 두어, 익명 인물 관찰과 신원·화자 연결을 분리하도록 한 번 더 명확히 지시했다. 한 그룹의 초기 visual moment 누락 등은 validator가 거부했고 수정 뒤 통과했다. 따라서 이 결과를 ‘수정 없는 첫 응답 정확도’로 해석하면 안 된다.

## 발견해 반영한 점

- 화면 가장자리에 걸친 얼굴의 원시 박스가 정규화 화면 밖으로 나갈 수 있었다. 가시 교집합과 `frame_edge_truncated`를 기록하고 원시 박스는 보존했다.
- 제한된 실행 환경에서 Vision이 샘플 0개로 끝날 수 있었다. 빈 결과를 성공으로 취급하지 않도록 실패 검사를 추가했다.
- 부분 복원 자막은 버리지 않고 `caption_uncertainty`로 후보 검토 사유에 남겼다. 문장이 열려 있거나 이웃 범위가 필요한 후보도 자동 확정하지 않는다.
- 익명 인물 관찰은 신원을 몰라도 남길 수 있도록 모델 계약을 명확히 했다.
- 옵션만 바꿨을 때 Vision까지 다시 계산될 수 있었던 캐시 의존성을 제거했다. 옵션 변경은 packet만 재생성하며 같은 설정은 전 단계 재사용하는 회귀 테스트를 추가했다.

## 기존 결과 호환

기존 397개 정본에서 2,200개 후보를 0.477초에 변환했고 범위·참조 처리 오류는 없었다. 이 변환은 로컬 JSON 처리이며 추가 LLM 호출·미디어 추출은 0이다. 새 인물·원음·사건 구조를 생성한 실험은 아니며 기존 후보의 새 정보는 미확인으로 남겼다.

## 검증과 한계

- Python 전체 테스트 125개 통과, 신규 모듈/test의 Ruff 검사 통과.
- Swift 최적화 컴파일과 실제 Vision 실행 통과.
- 독립 코드 리뷰의 설명 필드 타입 검증 누락을 수정하고 null/숫자 거부 테스트 추가.
- 신원/얼굴 부재/환경음 실제 청취/전체 편집 품질은 검증하지 않았다. STT 복원에 불확실성이 남는 자막이 있다.
- 다음 평가는 야생동물, 빙하, 열차, 주문/가이드 대화, 파티, 가림/반사 등 12–20개 대표 장면에서 별도 트리밍 필요 비율과 누락·오연결을 측정한다.
