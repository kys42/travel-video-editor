# README 이미지 출처

실제 분석 화면과 기존 완성 영상에서 가져온 이미지다. UI나 추출 내용을 재구성한 목업이 아니다. 2026-09-08 캡처한 최종 이미지 전체를 확인했으며 얼굴이 보이지 않는 화면만 사용했다. 블러·생성형 보정·합성을 적용하지 않았다.

| 파일 | 내용 | 캡처 조건 |
|---|---|---|
| `scene-library.png` | 2026-08-25 헬리콥터 비행 분석, G003 빙하 클립 목록과 구간 상세 | 검색으로 표시 영상을 제한하고 03:40 구간 선택. 실제 로컬 Editor Service 화면. |

화면 캡처 서버는 모델 재호출 없이 `demo` 채팅 backend로 실행했다. 라이브러리의 장면·대사·후보는 기존 실제 추출 결과다. 전체 여행 영상이나 개인 라이브러리 파일은 Git에 추가하지 않았다.
